# MahjongBump

微信小程序原生版麻将对对碰。当前主入口是 `pages/game/game`，使用 Canvas 绘制麻将牌、连线、选中光效和反馈动画。

## 项目结构

```text
.
├── app.js                 小程序启动入口
├── app.json               页面入口和导航栏配置
├── app.wxss               全局背景和基础样式
├── pages/
│   └── game/
│       ├── game.wxml      游戏界面：顶部信息、Canvas、底部按钮
│       ├── game.wxss      绿色桌面、大字体、大按钮样式
│       ├── game.js        游戏流程：点击、计分、倒计时、提示、洗牌、过关
│       └── game.json      游戏页标题配置
├── components/
│   └── board/
│       └── board.js       Canvas 棋盘绘制：麻将牌、选中光效、连线、粒子
├── utils/
│   ├── match.js           经典连连看连线算法，最多允许2次转折
│   ├── shuffle.js         剩余麻将洗牌，并保证洗牌后尽量有可消除组合
│   └── timer.js           60秒倒计时封装
└── assets/
    └── tiles/             麻将牌图片，使用英文文件名避免乱码和加载失败
```

## 玩法与功能

- 点击两张相同麻将牌，路径可连接且最多2次转折即可消除。
- 全部消除即过关。
- 倒计时60秒，超时失败。
- 连击会增加额外分数，点错会清空连击。
- 没有可消除组合时会自动洗牌。
- 提示按钮会自动标出一对可消除麻将；静置一段时间也会自动提示。

## 视觉与交互

- 背景是绿色麻将桌面。
- 麻将牌由 Canvas 绘制白底、圆角、阴影、高光，再贴麻将图片。
- 选中时放大并发光。
- 成功消除时显示白色光线连线和粒子效果。
- 错误点击会震动并红闪提示。

## 运行

使用微信开发者工具打开本目录，选择“小程序”项目即可预览。

旧的 H5 版本文件还保留在根目录，方便单独预览普通网页效果：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。
